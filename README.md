# Thiranex Task 1: Social Media Usage Analysis

**Thiranex Data Analyst Internship - Task 1 Submission**

### 📌 Project Overview
Analyzed social media usage patterns across 6 major platforms using Python to identify user behavior trends.

### 💻 Tools & Libraries Used
- Python, Pandas, Matplotlib, Seaborn

### 📊 Visualizations Created
1. **Daily Active Users by Platform** - Bar chart comparing user base
2. **Average Time Spent per User** - Platform-wise time analysis  
3. **Engagement Rate by Platform** - Engagement comparison
4. **Time Spent vs Engagement Rate** - Scatter plot for correlation

### 📈 Key Insights
- YouTube dominates with ~1950M daily active users
- TikTok shows highest engagement rate at ~9%
- Video platforms like YouTube & TikTok have 60+ min average daily usage

### 📁 Files
- `task1.py` - Python script for data analysis & visualization
- `dashboard.png` - 2x2 dashboard output with all 4 charts
